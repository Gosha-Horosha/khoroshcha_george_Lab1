# Лабораторная работа 1 — «Кто снизил активность и почему»

Всё по работе лежит в папке `khoroshcha_lab1/`:

- `01_analysis.ipynb` — рабочий ноутбук: сырые данные → аудит → очистка → журнал → разведка → метрика → группы;
- `02_report.ipynb` — отчёт для заказчика;
- `report.pdf` — собранный отчёт (4 страницы, 5 графиков);
- `cleaning_log.csv` — журнал изменений;
- `campaign_list.csv` — итоговый список кампании (`client_id`, `group`), 1 896 клиентов в 4 группах;
- `mkpdf.sh` — сборка `report.pdf` (html без кода → pdf через системный chromium).

## Запуск

1. `uv sync` — установить зависимости.
2. Положить выданные файлы в `data/clients.csv` и `data/transactions.csv` (в репозиторий не входят).
3. Выполнить `khoroshcha_lab1/01_analysis.ipynb` сверху вниз: он сохранит очищенные данные, журнал, список кампании и в последней ячейке соберёт `report.pdf`.
